ESD-Keys per CSV importieren

Eine Zeile je Key mit vier Spalten, getrennt durch Semikolon (Kopfzeile ist erlaubt):
Mandant; Artikelnummer; Key; Anzahl – z. B. OKAY;21882;852365-25412-25875-25185;1

„Anzahl“ ist, wie oft der Key vergeben werden darf (1 = Einzelkey). Die Artikel müssen als Typ A in der Kategorie Software angelegt sein und werden automatisch als ESD-Key-Artikel gekennzeichnet. Bei einem Fehler in einer Zeile wird nichts importiert.
